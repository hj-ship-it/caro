# Cờ Cá Rô - Tic Tac Toe Game

Game cờ cá rô (Tic Tac Toe) đơn giản được viết bằng HTML, CSS, và JavaScript thuần.

## Tính năng

- Chơi 2 người trên cùng một thiết bị
- Ghi nhớ điểm số qua các ván chơi
- Hiệu ứng animation đẹp mắt
- Responsive design - chơi được trên mọi thiết bị
- Lưu điểm số vào localStorage
- Đánh dấu các ô thắng cuộc

## Cách chơi

1. Mở file `index.html` trong trình duyệt web
2. Người chơi X đi trước
3. Click vào ô trống để đánh dấu
4. Người chơi đầu tiên có 3 ký hiệu liên tiếp (ngang, dọc, hoặc chéo) sẽ thắng
5. Nếu tất cả các ô đều được điền mà không ai thắng thì trận đấu hòa

## Cấu trúc file

```
├── index.html   # File HTML chính
├── style.css    # File CSS cho giao diện
├── game.js      # Logic game
└── README.md    # File hướng dẫn
```

## Công nghệ sử dụng

- HTML5
- CSS3 (với Flexbox và Grid)
- JavaScript (ES6+)
- LocalStorage API

## Tính năng nổi bật

- **Hiệu ứng Animation**: Pop animation khi đánh dấu, pulse animation cho ô thắng
- **Responsive**: Tự động điều chỉnh theo kích thước màn hình
- **Lưu điểm**: Điểm số được lưu tự động và không mất khi tải lại trang
- **UI hiện đại**: Gradient backgrounds, shadows, và smooth transitions

## Hướng dẫn cài đặt

Không cần cài đặt gì cả! Chỉ cần:

1. Clone repository này
2. Mở file `index.html` trong trình duyệt
3. Bắt đầu chơi!
